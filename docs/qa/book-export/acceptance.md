# 导出书本验收记录

日期：2026-10-23。隔离环境使用临时 SQLite、临时 output、127.0.0.1:3001 / 5174；不使用开发正文或调用模型。

## 自动化覆盖

- shared 契约：空书名、空格式、重复格式、非法章号；创作 STAGES 仍止于 prose。
- 内容转换：中文、标题去重、展示章名、正文小标题、段落、强调、特殊字符、不支持节点与位置诊断。
- 文件服务：项目隔离、路径穿越、符号链接及写入期间执行权变化。
- HTTP：成书配置 CAS、三模式复制、前文变更拦截、预览过期、请求幂等、三格式同快照、历史下载、格式失败重试、快照损坏、删除失败重试、执行中删除与重启恢复。
- 完整正文流程：manual/auto 逐章接受后导出三格式，不新增模型调用；项目删除及恢复继续按现有规则工作。
- 前端：未保存门禁、保存冲突保留编辑、阻塞诊断、导出请求、历史下载、格式重试和剪贴板失败手动复制。

新增依赖采用精确版本，许可均为 MIT：mdast-util-from-markdown 2.1.0、mdast-util-to-markdown 2.2.0、mdast-util-gfm 3.1.0、micromark-extension-gfm 3.0.0、fflate 0.8.3。Markdown 使用 AST，fflate 提供 Node 24 / ESM 可用 ZIP；未增加任务服务。
