# 种子修改摘要验收

日期：2026-10-23

## 实现范围

- 一次模型调用返回完整候选与简短修改说明，使用注册模板 `premise-revision/v2`。
- 服务端比对 17 个固定字段，过滤虚报、补齐漏报，前后原文来自实际种子对象。
- 候选与摘要原子存储；请求去重读取原摘要；旧候选和损坏摘要可兼容降级。
- 完整候选上方展示「本次修改」、项数、中文字段和说明，可展开前后原文，超过五项可展开其余项。
- 新一轮失败保留输入、旧摘要和旧候选；采用与放弃时成套清除预览。
