# 正文按建议修改验收

日期：2026-10-25。

## 已实现

- 移除工作台本地编辑、刷新本地修改、候选稿生成和展示；旧 regenerate 接口返回 410。
- 当前审核建议逐条勾选、默认不选、支持全选清空；支持独立补充要求，空请求拒绝。
- 后端根据有效报告及索引解析建议；只将所选条目交给修订模型，检查逐条响应索引。
- 先展示原文/新文实际段落差异，再查看全文、应用或放弃。修改输入或选择后旧预览不可直接应用。
- 建议和任务持久化，页面重载可恢复；生成失败保留上一份成功预览，输入草稿按项目/章号存放。
- 应用检查版本、哈希与依赖，保留原文快照，受控发布并使后文依赖失效；自动重审和摘要，仍需人工接受。
- 应用后审核失败保留修改，可只重试机器步骤；发布后中断通过哈希和应用日志恢复。
- 有可信快照时可恢复丢失/损坏正文；正常正文禁止以恢复操作覆盖。
- 迟到结果不能应用；取消后已发生的修订用量独立记录。

## 自动化验证

- 新增修订服务、真实差异、版本、选择范围、幂等、冲突、放弃、恢复、取消、计费回归。
- 新增 HTTP 创建/查询/应用流程与旧接口下线测试，保留历史候选兼容读取回归。
- 新增前端选择、全选清空、输入、旧报告、预览版本及失败保留测试；调整原工作台用例。
- 增加完整正文结构化输出截断检查及回归。
- 全仓库默认并行测试曾出现共享 SQLite 锁超时和旧页面测试超时，另外串行复核；详见实施反馈中的最终结果，不把并行失败记为通过。

## 页面核验

在已有四章项目上检查新模块，六条审核意见默认不选；勾选第 1、3 条显示已选 2/6，清空后恢复 0/6 且生成按钮禁用。检查结束已清空临时选择，没有调用真实模型或应用修改到该作品。

桌面截图：`desktop.png`。窄屏检查发现侧栏挤压正文，已仅针对正文工作台改为顶部导航；窄屏 DOM 测量正文卡片宽度约 335 CSS px，页面宽度等于视口宽度，无横向溢出。浏览器窄屏截图接口返回空白，因此不将该截图作为视觉验收证据。

## 待验收范围

真实模型的局部润色、整章重写、不同审核建议组合的修改质量尚未运行样例验收。自动化测试使用模拟模型，不能证明模型会充分落实每条建议或完全保留未涉及内容；作者仍需核对真实差异后应用。
