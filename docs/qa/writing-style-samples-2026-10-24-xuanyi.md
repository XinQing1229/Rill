# 短篇爽文真实模型小样对照

日期：2026-10-24

范围：三组固定章纲的正文小样，比较通用策略和短篇爽文 v1。不是完整小说或商业效果验证。调用现有 LlmService、模型配置与正文模板，不运行项目流水线。

## 悬疑与紧张

固定事件：证物室管理员许言被指控调换证物。她已发现交接单时间与门禁停电时间矛盾，停电时门只能从里面打开。她在复核会上对照两份记录，证明值班主管提前进入并伪造交接。主管承认违规取走证物，许言洗清嫌疑。不能凭空加入证据。

### 通用策略

模型：deepseek-flash；用量：输入 243 / 输出 678 tokens。

证物室的灯管闪了两下，许言没抬头。她正把三号柜的交接单按日期排开，指尖压着纸角，一页一页翻得极慢。门口传来脚步声，不止一个人。

“许言，复核会提前了。”值班主管周成靠在门框上，手里捏着一份材料，“有人反映三号柜的毒品证物封条被换过，时间对不上你的班。”

她终于抬起头，看了一眼周成身后的两个纪检人员，把手里的交接单合拢，卷成一个筒。“那正好，我也有点东西要对。”

会议室不大，长桌一头坐着分管副主任，周成坐对面，纪检的人分列两侧。许言把交接单摊开，又把门禁记录打印件推过去。

“三号柜最后一次合规交接是上周四下午五点，我签的字。”她指着单子最下面一行，“但当天晚上九点，门禁记录显示有人刷开了证物室的外门。”

周成插话：“你也在值班表上，那天你值夜班。”

“我值夜班，但我六点进的门，七点半就出去了。门禁记录上有。”许言翻到第二页，用指甲划出一条线，“九点那次刷卡用的不是我的卡号。卡号尾数零七，是你的。”

周成脸色没变，但手指在桌面上停了一下。“我进去拿卷宗，跟证物无关。”

“问题就在这儿。”许言把停电通知单拍在桌上，“当晚八点半到十点，整栋楼停电。门禁是电子锁，停电以后只能从里面手动开。你九点刷卡——系统为什么会有记录？”

会议室安静了几秒。副主任低头看门禁记录，又看停电通知，眉头皱起来。

“停电期间刷卡记录是恢复供电后补传的。”许言说，“但补传时间戳不会变。九点整的刷卡时间，锁根本没电，刷不开。除非——”她转向周成，“你是八点半之前就进了证物室，等停电以后从里面手动开的门，出来以后再拿卡刷了一遍，让系统以为你九点才来。”

周成张了张嘴。

“你提前进去，取走了三号柜的封条样本，换了一份假的。然后停电时从里面开门离开，再把卡刷一遍做时间证明。”许言把交接单翻到背面，上面有一行手写的备注，字迹潦草，“这张交接单背面写了个‘补’字，不是你签的，是后来有人替你补记录的笔迹。”

周成盯着那张纸，喉结动了一下。

“我承认。”他声音低下去，“那天我进去拿了点东西，封条是我不小心弄破的，我怕担责任就换了一个。跟毒品案没关系，就是怕写检查。”

副主任把材料一收，看了纪检的人一眼。“先停职，写书面说明。”

许言把交接单收回文件夹，站起来。周成经过她身边时顿了一下，没说话。她也没看他，把三号柜的钥匙交到副主任手里，转身出了会议室。走廊尽头的窗户开着，风灌进来，她这才发现后背的衬衫已经湿透了。

### 短篇爽文 v1

模型：deepseek-flash；用量：输入 417 / 输出 519 tokens。

复核会的长桌尽头，摆着两份记录。

许言站在桌边，没坐。对面是值班主管周立，翘着腿，指节叩着桌面，一下一下，响得不紧不慢。

“证物室当晚只有你一个人有交接权限，”周立说，“封条断在你当班时段，不是你还能是谁？”

“那就看时间。”许言把第一份记录推过去，“交接单写着，当晚十点零三分，我把三号柜的证物交给你。”

“白纸黑字。”周立扫了一眼。

“可门禁系统记录，九点四十分到十点十分，证物室整层停电。”她又推过去第二份，“你告诉我，十点零三分，我人怎么在门禁失效的屋里做交接？”

周立的手指停了一下。

桌尾有人低声翻纸。

许言没停：“证物室的门，停电时只能从里面手动开。也就是说，十点之前屋里有人。交接单上写的是我从外面进来交给你——可那段时间，谁都进不来。”

“停电记录也可能错了。”周立说。

“两份记录，一份是门禁系统自动生成的，一份是你签字的交接单。”许言把两张纸并排摆好，“我核对过值班表。你九点三十八分签了提前到岗，比交接单上的时间早了二十五分钟。”

周立的腿放了下来。

主持会议的副主任终于开口：“周立，你提前进证物室做什么？”

“取一份材料……”周立的声音低下去，“我、我忘了补交接单，想着先拿走，后头再补。”

“补成许言交给你的。”副主任把交接单拎起来，抖了抖。

会议室安静了几秒。周立站起来，椅子向后一退，刮出刺耳的响：“我承认，那晚是我进去取的，单子是我事后填的，时间写错了。”

“不是写错。”许言盯着他，“是写反了。把你自己写成接交人，把锅扣给我。”

周立没接话。副主任合上文件夹：“违规取走证物、伪造交接记录，两件事都报上去。许言，交接权限恢复，今晚继续值班。”

许言点头，收起自己那份记录，转身往门口走。

身后周立还在解释“只是图省事”。她拉开门，没回头。走廊灯亮得很稳，门禁屏幕上的时间跳成整点，一格一格往前走。
